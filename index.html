01 / Hardware
Sense & actuate

RealSense D415 depth camera; Jetson Nano; six RS-485 servo drives with 17-bit encoders and 50:1 gearboxes; ESP32 micro-ROS bridge.

02 / State
Estimate motion

ORB-SLAM2 CUDA supplies visual pose and sparse map points. A ROS 2 C++ observer unwraps motor encoder counts; the Klann model estimates body motion from the legs.

03 / Fusion
Keep planar odometry

A weighted fusion node combines leg-based odometry with visual motion and publishes the planar odom → base_link transform for downstream mapping.

04 / Mapping
Prepare navigation maps

A ROS 2 UDP bridge exposes pose, map points, and a virtual scan. slam_toolbox builds an occupancy grid for visualization and Nav2 planning inputs.

Engineering decision

Visual SLAM is the primary localization source; body-kinematic odometry provides a fallback and fusion input when visual tracking degrades or the camera is occluded. Keeping the map transform planar also avoids injecting unstable roll and pitch into a 2D map.

Validation & scope

Teleoperated straight-line odometry was reported within the project’s 6-inch tolerance. The report identifies the kinematic scale as a remaining calibration parameter; autonomous stage goal selection is a target use of the map, not a claimed completed demonstration.
